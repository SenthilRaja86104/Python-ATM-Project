# 🏧 Python ATM Management System

## 📌 Project Description
A simple ATM Management System developed using Python. This project simulates basic ATM operations using conditional statements (if, elif, else).

## 🚀 Features
- PIN Verification
- Check Account Balance
- Cash Withdrawal
- Cash Deposit
- Minimum Withdrawal Amount: ₹500
- Maximum Deposit Amount: ₹1,00,000
- Invalid PIN Validation
- Amount Validation

## 🛠️ Technologies Used
- Python 3

## 📚 Python Concepts Used
- Variables
- Data Types
- User Input (`input()`)
- Conditional Statements (`if`, `elif`, `else`)
- Logical Operators (`and`)
- Arithmetic Operators

## 💻 How to Run the Project

1. Install Python 3.
2. Clone or download this repository.
3. Open the project folder.
4. Run the following command:

```bash
python atm.py
```
